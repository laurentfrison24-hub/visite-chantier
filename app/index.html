Configuration une seule fois

  1. Sur GitHub, créez un jeton fine-grained avec Contents: Read and write uniquement sur le dépôt visite-chantier-inbox.
  2. Collez le jeton ci-dessous. Il reste sur cet iPhone (jamais envoyé ailleurs).
  3. Ensuite, « Envoyer à Aide Chantier » dépose le dossier sans feuille de partage.

Sans webhook, Aide Chantier peut quand même récupérer le dossier via le dépôt (routines 12:14 / 18:14) ou Gmail.
